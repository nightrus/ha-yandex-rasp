# Яндекс.Расписания — электрички для Home Assistant

Интеграция показывает ближайшие электрички по станции через официальный
[API Яндекс.Расписаний](https://yandex.ru/dev/rasp/doc/ru/) и включает
карточку-табло для дашборда.

## Установка

**HACS:** HACS → ⋮ → «Пользовательские репозитории» → URL этого репозитория,
категория «Интеграция» → установить → перезапустить HA.

**Вручную:** скопировать `custom_components/yandex_rasp` в
`/config/custom_components/` и перезапустить HA.

## Настройка

Настройки → Устройства и службы → «Добавить интеграцию» →
«Яндекс.Расписания — электрички».

- **Ключ API**: бесплатно на <https://developer.tech.yandex.ru/>
  («API Яндекс.Расписаний»), 500 запросов в сутки.
- **Станция**: введите название или его часть («бескудн», «савёловский»),
  затем выберите станцию из списка (с направлением и городом). Можно ввести и
  код станции (`9601805`). Можно добавить несколько станций.
- **Сменить станцию**: ⋮ у записи интеграции → «Перенастроить».
- **Интервал обновления** (кнопка «Настроить»): по умолчанию 30 мин, минимум 15.
  Одно обновление ≈ 4 запроса (в сутках ~300 рейсов, по 100 на страницу).

## Сущности

`sensor.<станция>_blizhaishaia_elektrichka`: время ближайшего отправления
(timestamp). Атрибуты:

| атрибут | |
|---|---|
| `station`, `station_code` | станция |
| `directions` | направления, «на Москву» первым |
| `departures` | отправления на 3 часа вперёд: `departure`, `number`, `title`, `direction`, `express`, `subtype`, `color`, `stops`, `platform` |
| `updated` | время последнего запроса к API |

Состояние пересчитывается каждую минуту по уже загруженным данным, без
обращения к API.

## Карточка

Интеграция сама подключает карточку, ресурс добавлять не нужно. Два столбца:
слева «на Москву», справа обратное направление; фон берётся из темы.
Все параметры доступны в визуальном редакторе карточки.

```yaml
type: custom:yandex-rasp-card
entity: sensor.elektrichki_beskudnikovo_blizhaishaia_elektrichka  # необязательно
hours: 1        # окно в часах (до 3)
rows: 6         # строк в каждом столбце
title: Бескудниково  # необязательно
```

## Справочник станций

`custom_components/yandex_rasp/stations.json.gz` — ж/д станции России из
`stations_list` API (~13,8 тыс., 200 КБ). Обновить:

```sh
python tools/build_stations.py <API_KEY>
```
